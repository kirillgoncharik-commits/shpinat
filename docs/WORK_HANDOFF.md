## 1. Cloudflare Pages

Для проекта с Git integration подключи этот репозиторий:

| Настройка | Значение |
| --- | --- |
| Production branch | `main` |
| Framework preset | None |
| Build command | `exit 0` |
| Build output directory | `public` |

В `wrangler.toml` указано подтверждённое имя существующего проекта `shpinat-pilot` (Direct Upload). Конфигурация существующего проекта должна быть сохранена.

При Direct Upload загрузи **содержимое** `public/`, чтобы `index.html` находился в корне. Выбери способ обновления, который поддерживает существующий проект.

Подключи shpinat.club как custom domain, внеси необходимые DNS-записи и дождись рабочего HTTPS. Сохрани остальные DNS-записи, включая почтовые. Домен повторно не покупай и платные услуги не включай.

## 2. Google Analytics 4

Проверь существующие ресурсы и веб-потоки для shpinat.club, чтобы не создать дубликат. При необходимости создай ресурс в подходящем аккаунте пользователя, часовой пояс `Europe/Belgrade`, веб-поток `https://shpinat.club/`.

Настоящий Measurement ID `G-F6FZB994ZD` уже внесён в `public/site-config.js` в поле `ga4MeasurementId` и опубликован. Google tag загружается после согласия посетителя.

Код `public/analytics.js` уже:
- включает аналитику только на shpinat.club и www.shpinat.club;
- загружает Google tag после согласия посетителя;
- отключает Google Signals и рекламную персонализацию;
- передаёт `booking_click` с расположением кнопки;
- позволяет изменить выбор в настройках аналитики.

Опубликуй конфигурацию с ID. Проверь отсутствие загрузки Google tag до согласия и при отказе; после согласия проверь загрузку тега и поступление `page_view` и `booking_click`. При отзыве согласия последующие события должны блокироваться.

Нажатие Calendly не является состоявшимся бронированием; не называй его подтверждённой заявкой. Встречу не бронируй.

## 4. Индексация и проверка

На shpinat.club должны быть разрешены обход и индексирование, canonical должен указывать на соответствующую страницу основного домена.

На временных адресах pages.dev должны сохраняться `X-Robots-Tag: noindex, nofollow`. Правила в `public/_headers` уже разделены по имени хоста. Общий noindex для основного домена возвращать не нужно.

Проверь:
- главную, `/program/`, `/privacy/` и корректный 404;
- все четыре фотографии, логотип, CSS и JS;
- мобильное меню и раскрывающиеся блоки программы;
- отсутствие горизонтального скролла на телефоне;
- все кнопки записи: `https://calendly.com/kirillgoncharik/30min`;
- HTTP-заголовки основного и временного доменов;
- работоспособность CSP с реальным Google tag.

Перед публикацией выполни `python3 scripts/validate_site.py` и проверку синтаксиса `node --check public/analytics.js`.
